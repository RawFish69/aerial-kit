# The AK_USB_TRACE flash pages, as hex - 2026-09-27
#
# These are the raw pages the records in f405-usb-trace.txt were decoded from.
# They are stored as text rather than as .bin files because `firmware/.gitignore`
# ignores `*.bin` deliberately - that rule exists so build images never land in
# the repository - and a 12 KB blob is not worth an exception to it.
#
# Reconstruct a page before decoding it, so the reader's own FNV-1a check is
# what says the bytes are intact rather than this transcription. Each heading
# below starts one 4096-byte page, in order:
#
#   python3 - <<'PY'
#   raw = bytes.fromhex("".join(l.strip() for l in open("f405-usb-trace-pages.txt")
#                              if l.strip() and not l.startswith("#")))
#   open("hsi.bin", "wb").write(raw[:4096])    # the first block
#   open("hse.bin", "wb").write(raw[4096:])    # the second
#   PY
#   scripts/trace-page.py hsi.bin
#
# That is how the file was checked before it was committed, and it decodes back
# to the two records printed in f405-usb-trace.txt.
#
# Each page is 4096 bytes, 0x0801F000 to 0x0801FFFF, the last page of the
# sector the image lives in. A slot is 64 bytes and they fill from the bottom,
# so slot 0 is the first 64 bytes of the page. Erased flash reads FF, which is
# most of both of these - only the first slot or two carry a record.
#
