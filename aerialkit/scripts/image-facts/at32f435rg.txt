# AT32F435RGT7 - the facts scripts/check-image.sh measures a built image
# against, for the wing's own board (src/boards/AERIALKIT_GHF435/). See that
# script for what each one proves, and src/arch/at32f435/vectors.h for the
# table these entries are the ends of.
#
# stack-top is the top of the RAM region linker/at32f435rg.ld maps: 128 KB at
# 0x20010000. (The script at 0x10000000 is the second region and is not the
# one the hardware loads the stack pointer from.)
#
# vector-words is 16 + the highest interrupt this firmware uses. On this part
# that is DMA1 channel 2 at 57, so 16 + 57 + 1 = 74 words - eighteen more than
# the F405's table, whose last entry is interrupt 39.
#
# Each vector line is: index, the symbol the entry must point at, and what
# stops working if it does not.
stack-top 0x20030000
vector-words 74
vector 3 HardFault_Handler a fault leaves no record
vector 15 SysTick_Handler the clock stops
vector 53 USART1_IRQHandler the console goes deaf
vector 54 USART2_IRQHandler the receiver hears nothing
vector 55 USART3_IRQHandler the gps never reports a fix
vector 72 DMA1_Channel1_IRQHandler the first motor's DShot frame never completes
vector 73 DMA1_Channel2_IRQHandler the second motor's DShot frame never completes
