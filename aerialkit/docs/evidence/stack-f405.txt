# ---- what this does not say -------------------------------------------------
#
# The graph has no edges through function pointers, and this firmware passes
# drivers around as tables: 506 call sites are counted as zero, so 2,480 is a
# floor and 8,584 is one largest-frame call at every one of them, which cannot
# be true of all of them at once. The truth is between the two. Nothing here
# was run on a part, so nothing here says what a real overflow would do.
