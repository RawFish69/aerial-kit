# Shared protocol vectors

This directory holds protocol fixtures that are consumed by the Python library,
firmware tests and the web configurator. A vector is a wire payload plus the
meaning that both ends must recover from it.

The files are generated by `generate_vectors.py` and checked by
`check_vectors.py`:

```bash
python -m pip install pymavlink==2.4.49
python protocols/generate_vectors.py
python protocols/check_vectors.py
```

Generation is deterministic. The checked files contain no timestamps or
environment-specific paths.

## Schema

Every file has:

```json
{
  "schema_version": 1,
  "protocol": "crsf | akp | mavlink | akp-over-crsf",
  "source": {},
  "cases": []
}
```

Common case fields:

| field | meaning |
| --- | --- |
| `name` | stable identifier, unique within the file |
| `raw_hex` | complete wire frame |
| `payload_hex` | frame payload, excluding address, length and checksum |
| `decoded` | the values the frame represents |
| `write` | true when carrying this frame could mutate device state |

CRSF cases also carry `address` and `frame_type`. AKP cases carry the command
number and whether the frame is a response. MAVLink cases carry message id,
sequence, source ids and `crc_extra`.

The AKP-over-CRSF file additionally documents the provisional segmentation
header and contains reassembly and loss cases. Its acceptance is not a claim
that the pinned ExpressLRS build forwards the CRSF MSP envelope end to end;
that is checked before the radio transport is enabled.

## Sources

| file | authoritative source |
| --- | --- |
| `vectors/crsf.json` | ExpressLRS 4.1.0 CRSF structs and Aerial Kit's firmware encoder |
| `vectors/akp.json` | `firmware/src/core/ak_proto.*`, `firmware/docs/16-protocol.md`, captured configurator frames |
| `vectors/mavlink.json` | pymavlink 2.4.49, MAVLink v2 common dialect |
| `vectors/akp-over-crsf.json` | the CRSF MSP frame definitions plus the AKP frame format |

The checker recalculates lengths and checksums itself. It does not import the
library encoders that the incoming implementation will exercise, so a shared
encoder bug cannot make a vector self-consistent merely by agreeing with
itself.
